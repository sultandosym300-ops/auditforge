# Последовательное расследование: отдельная версия после Genesis

Исходный коммит 482fb92; исходный релиз genesis-2026-fintech-final неизменяем.
Рабочая ветка feature/sequential-investigation-v1. Стандартный генератор,
официальные пять инструментов, reward и закрытый evaluator сохраняются.

## Реализация и порядок проверки

1. Независимый аудит исходного набора, reference evaluator и регрессии.
2. Отдельный investigation_v1: несколько связанных аудиторских направлений,
   последовательное получение пакетов документов, неодинаковая стоимость,
   чистые/смешанные компании и полноценные финансовые доказательства.
3. Единый public-only runner: random-valid, fixed, reconciliation,
   budget-aware, greedy и hypothesis search; одинаковые API/бюджеты.
4. Компактные REINFORCE и actor-critic; обучение только на train,
   выбор на validation; замороженный test и отдельный transfer holdout.
5. Ablations, парный bootstrap по компаниям, финансовый аудит и
   метаморфные проверки. Отрицательное преимущество допустимо и сохраняется.
6. Интеграция в Training Lab без изменения оформления/3D; реальные вычисления,
   импорт/экспорт с валидацией; browser E2E и сборка.
7. Новые отчёты, CI, отдельный ZIP/релиз после проверки распакованной копии.

## Риски и решения

- Доступных локальных docker/gh пока нет в PATH: найти установленный CLI;
  при отсутствии Docker проверять существующим GitHub CI, а не имитировать.
- Сложность новой задачи не гарантирует превосходства RL. Не менять оценщик,
  baseline или test после результатов; сохранять каждый запуск.
- Публичные финансовые признаки могут содержать законные сигналы риска;
  отдельно проверять технические shortcut (ID/порядок/имена/seed).
- Браузер открыт владельцу. Закрытая оценка только через изолированный брокер.
