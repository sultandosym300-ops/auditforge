# Проверенные границы

**IMPLEMENTED / VERIFIED:** Python-ядро, четыре причинных ошибки, два связанных сценария, чистые истории, Decimal, двойная запись, reset/step, пагинация, безопасный калькулятор, лимиты, точный matcher, терминальная награда, четыре политики, реальные траектории, воспроизводимость, 10 train + 10 dev, сайт и автономное исполнение ядра через WASM.

**PARTIALLY VERIFIED:** изоляция. Отдельный процесс оценщика и stdio-граница проверены. Доверенные Python-адаптеры имеют API host-процесса; им нельзя передавать произвольный недоверенный код. Для такого кода предусмотрен отдельный контейнер без сети и private файлов.

**NOT TESTED HERE:** Docker отсутствует на рабочем компьютере. Dockerfile, отсутствие private файлов в образе policy и флаги ограничения подготовлены, но сборка, OS-изоляция и измерения внутри 2 CPU / 4 GB Linux-контейнера не проверены фактическим запуском. Тег базового образа не фиксирует digest; для архивной идентичности следует зафиксировать digest доступного образа при подготовке контейнера.

**NOT TESTABLE LOCALLY:** закрытые 20 эпизодов, 20 проверок контракта и reward, 20 пар организаторов, официальная инженерная оценка. Локальные тесты — собственная приближённая проверка опубликованных требований. Официальные 100/100 неизвестны.

Браузерный Worker является учебным оценщиком; пользователь браузера контролирует его и может изучить исходники. Он не используется для официальной закрытой проверки. Pyodide поставляет собственную версию Python; CLI целится в Python 3.11. Побитовая идентичность CLI/WASM между версиями Python отдельно не заявляется.

Синтетическая экономика ограничена одной моделью кредиторской задолженности: счета в KZT, платежи в KZT/USD/EUR/JPY, возвраты и погашения. Это прозрачная проверяемая модель, не полная система бухгалтерского учёта. Сильная сверка достигает F1=1 на локальном наборе; это признак разрешимости этих сценариев, а не доказательство сложности для произвольной модели.

Первичный источник финансовых доказательств — открытые структурированные документы; OCR, реальные счета и документы пользователей не обрабатываются. Финансовое заключение, банковские платежи и хранение персональных данных не предусмотрены.

SF Pro запрашивается как системный шрифт. Там, где он не установлен, используется самостоятельный Manrope с кириллицей и казахскими глифами. Файлы Apple и исходное видео Apple не распространяются.
