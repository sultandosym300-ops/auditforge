# AuditForge 2.0.1 и результат аудита

Контрольный коммит caf98acaf0e5c5b1dd74d516325aaae18536a3ba сохранён тегом auditforge-2.0.1-control.

Решение — сохранить рабочее ядро. Исходники auditforge не изменены, формат API и формула награды совпадают с baseline. Поэтому одинаковые конфигурации дают те же данные и оценки. Финансовые улучшения, изменения reward и усложнение генерации не приняты ввиду отсутствия подтверждённого дефекта.

| Свойство | Baseline | Итог |
|---|---|---|
| Генератор, matcher, reward, API | 2.0.1 | тот же код |
| Финансовый результат на одинаковом вводе | детерминирован | идентичен |
| Ошибки закрытого этапа | неизвестны | неизвестны |
| Pairwise-покрытие и эффективные взаимодействия | отдельно не подсчитано | 354 пары, 24/24 активных counts × interaction |
| Публичное расследование плотной книги | прежний пример | новая независимая проверка 2000/200 за 47 шагов |
| Адаптивный выбор запросов | не измерен | train/dev-подбор, отдельные 384 test-эпизода |
| Независимые доказательства | прежние абляции | восстановление суммы из предъявленных документов для 396 находок |
| Мутации | 16 | 19, включая FX-историю и компенсирующиеся миры |

Время генерации, память рабочего ядра и размеры его данных не изменены. Время расширенной проверки увеличивается за счёт новых испытаний, оно измеряется в reports/ultimate-jury.json. Размер отчётов увеличен, суммарный лимит сдачи проверяется CI.

Исправлен подтверждённый пробел тестового покрытия: три сочетания counts × interaction встречались только с отключающим ошибки clean. Добавлены активные конфигурации и независимый подсчёт покрытия. Это измеримое улучшение испытаний.

Не принята идея считать зеркальную cash-проводку без affected payable-документа полноценной заменой доказательства. Она не устанавливает конкретный заявленный ID. Графовые признаки подтверждённых дубликатов не объявлены shortcut, поскольку они описывают реальное повторное признание и сопровождаются источником.

Адаптивная политика получила 26 TP против 256 у полноценной сверки и не приблизилась к её награде. Эксперимент ограничен опубликованными моделями и сценариями. Новая исследовательская выборка не доказывает универсальную устойчивость.
