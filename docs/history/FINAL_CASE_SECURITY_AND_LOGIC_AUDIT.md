# AuditForge 2.0.1 · финансовый и логический аудит

Контрольная версия — b77ad073daeb8ca3358faeed0d5ae100c909eb2d, тег auditforge-2.0-control. Финальный SHA новой версии определяется командой git rev-parse main после успешного CI и переноса проверенной ветки. Отчёт относится к коду 2.0.1 и сопровождающим JSON в reports.

## Реальный дефект и исправление

Общая для всех компаний недельная формула котировки позволяла восстановить значения курса без их анализа. На 64 отложенных компаниях политика получила F1=1, все 6336 котировок были предсказаны. Строки доказательств она продолжала запрашивать. История курсов заменена детерминированной историей конкретной компании. На той же выборке и дополнительной независимой выборке F1 формульной политики составил 0,088235, точных котировок — 0/6336. Полноценная сверка сохранила F1=1. Все отправки соблюдали лимит 30 находок.

Дополнительные бинарные классификаторы выявляют некоторые ошибки по числу проводок или сводным суммам. Такие показатели сами могут быть финансовой уликой. Проверялись отдельные полноценные отправки с ID, суммой, валютой и доказательствами. Поверхностная комбинированная модель не получила TP. Подробные результаты находятся в SHORTCUT_HUNTER_REPORT.md.

## Воспроизведение

Запустите с Python 3.11 из корня проекта.

python -m scripts.jury_gauntlet --seed 974103116573 --report-dir work/shortcut-jury-final

python -m auditforge.shortcut_hunter

python -m scripts.adversarial_logic

python -m scripts.generator_probe --output work/probe.json

Workflow выполняет это без сети и GPU с двумя CPU и 4 GiB памяти, проверяет размер исходников и образов, затем запускает обычную политику в отдельном ограниченном контейнере. Результат конкретного коммита доступен в GitHub Actions. Локальная шкала и дополнительные диагностические показатели сохранены раздельно.

Для воспроизведения исторического сравнения из архива включён исходник контрольного генератора в scripts/controls/generator_114.py с проверкой SHA256. Он используется только сравнительным испытанием. Политика и рабочая среда используют текущий генератор.

Ограничения — конечное число моделей, сценариев и семейств. Классификация наличия ошибки не равна находке. Нулевой успех одной формулы не исключает других предсказуемых связей. Контейнерная граница доверяет хосту и оценщику. Официальную оценку выставляет жюри.
