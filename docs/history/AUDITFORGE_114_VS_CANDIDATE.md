# Сравнение 1.1.4 и кандидата 2.0

Решение — PARTIAL ACCEPT. Принят дополнительный сценарий перекрёстного отнесения двух обязательств к периоду. Базовая версия сохранена тегом `auditforge-1.1.4-control` на коммите `e722984569a30dfdb69a938a0c35882ca1b886e5`.

В 1.1.4 смена конфигурации чистой и ошибочной компании меняет всю генерацию. Новый сценарий строит четыре состояния одной истории. Два равных обязательства могут обменяться датами признания. В ошибочных состояниях одно обязательство завышено, другое занижено, а общие расходы совпадают.

| Измерение | 1.1.4 | Кандидат |
|---|---:|---:|
| Основная отложенная выборка | 128 компаний | 256 компаний |
| Независимая проверка финансов | 128/128 | 256/256 |
| Точный повтор генерации | 128/128 | 256/256 |
| Семьи с одинаковым содержимым одного источника при разных правильных ответах | 0/64 | 64/64 |
| Определение наличия ошибки по числу и сумме операций | 99,22% | 50% |
| Комбинация поверхностных признаков | 99,22% | 50,39% |
| Полная публичная сверка, F1 | 1 | 1 |
| Специализированная сверка периода, F1 | 1 | 1 |
| Среднее число шагов полной сверки | см. JSON | 13,39 |
| Среднее число шагов сверки периода | см. JSON | 8,95 |

Числа относятся к основному эксперименту с корнем `6982734491033`. Каждая семья целиком отнесена к обучающей или отложенной выборке. На 32 семьях выбирали правила, на 64 проверяли их. Bootstrap учитывает зависимость четырёх состояний одной семьи. Для комбинации признаков интервал точности кандидата 44,53–56,25%. Отдельная подтверждающая выборка с корнем `272104686017` дала 47,66% для комбинации и 50% для агрегатов при F1 публичного расследования 1 на всех 256 компаниях.

Это улучшение контролируемой сложности финансовой задачи. Угадывание агрегатов уже в 1.1.4 не давало подтверждённых находок с правильными доказательствами. Эксперимент не измеряет обучение весов или преимущество над другими командами.

Генерация кандидата занимает примерно на 0,35 мс больше на медианном примере. Размер сериализованной компании увеличился на десятки байт. Точные замеры времени, памяти, конфигурации и хеши исходников находятся в [основных результатах](../../reports/world-comparison.json) и [подтверждающих результатах](../../reports/world-confirmation.json). Время зависит от компьютера.

Новый сценарий охватывает ошибку отчётного периода. Остальные три типа и комбинированные ошибки доступны в стандартных конфигурациях. Риск комбинированных эвристик сохраняется. Равенство отдельных представлений и сводных сумм гарантируется конструкцией и проверяется для каждой семьи.

Воспроизведение с Python 3.11 выполняется командой `python -m scripts.world_comparison`. Подтверждение — `python -m scripts.world_comparison --seed 272104686017 --output work/confirmation.json`. Эти два корня поддерживают запуск из архива без истории Git за счёт проверки полного хеша контрольных данных. Для произвольных контрольных выборок нужна история исходной версии.
