# Воспроизводимая демонстрация нового исследования

Это дополнение после сдачи Genesis. Прежний сценарий и архив сохранены.
Демонстрационная компания зафиксирована в обоих протоколах **до** тестов:
seed `202611230017`, профиль `investigation_v1`, шесть направлений.
Первый checkpoint выбран по позиции training seed, не по успешности демо.

```sh
python -m unittest discover -s tests -q
python -m scripts.sequential_acceptance
python -m scripts.sequential_demo --output work/sequential-demo.json
```

| Стратегия | Действия | TP / FP / FN | F1 | Reward |
|---|---:|---|---:|---:|
| Random-valid | 5 | 0 / 0 / 1 | 0 | −1 |
| Обычная полная сверка | 10 | 0 / 0 / 1 | 0 | −1 |
| Сверка с учётом бюджета | 8 | 1 / 0 / 0 | 1 | 0.986 |
| Обученный Actor-Critic | 10 | 1 / 0 / 0 | 1 | 0.982 |

RL проигрывает сильной сверке по цене действий. Этот результат не заменён
более красивым seed. Компания содержит много корректных обязательств и одно
проверяемое нарушение; совокупная статистика обеих исследований важнее примера.

В JSON для каждого шага есть официальный action, полученный observation,
reward/flags и пояснение выбора. Для модели показаны реальные признаки,
вероятность выбранного запроса и линейный score; для эвристики — её оценка.
Это не скрытые рассуждения и не посмертная выдумка. Находки содержат записи,
суммы, валюту и source IDs. Скрипт независимо повторяет **каждое** действие и
проверяет совпадение ответов и финального отчёта.

На сайте: войти гостем → закрыть/пройти вводную → «Обучение ИИ» →
«Финансовый мир» → «Последовательное расследование». Выбрать бюджет и алгоритм,
создать модель, обучить; validation-точки появляются каждые 25 эпизодов.
Доступны отдельные validation/test-панели, экспорт/импорт JSON и сравнение
расследований с раскрываемыми документами. Все метрики вычисляются Python в
Web Worker. Остановка завершает текущий эпизод. Проверка не обновляет веса.

Для зафиксированного результата импортировать
`reports/final-sequential-selected-0.json`; обучение в браузере до импорта
создаёт другую настоящую модель и не обязано повторять эту таблицу.

Закрытая демонстрация после сборки:

```sh
docker build -f Dockerfile.sequential-policy -t auditforge-sequential-policy:1.0 .
python -m scripts.sequential_container
```

Это реальное контейнерное исполнение: без генератора/оценщика в образе агента,
без сети, с read-only filesystem и ресурсными ограничениями. Браузер этим
контуром не является. В Proof Center внешнее подтверждение привязано к
коммиту и успешному CI; оно не заявляет официальных 100/100.
