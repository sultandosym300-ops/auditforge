# Генезиз — единственный рабочий проект

Эта папка содержит весь действующий код AuditForge: Python-ядро, React-интерфейс, тесты, данные, конфигурации, документацию, ресурсы, собранный сайт и Git-историю.

По прямому указанию пользователя всегда работайте строго на основе этого проекта. Не создавайте параллельную реализацию или новую копию исходников в другом каталоге. Выполняйте команды из этой папки; пути стройте относительно корня проекта, а не прежнего имени `auditforge`.

## Основные команды

- Сборка сайта: `npm run build`.
- Полная проверка ядра: `py -3.11 -m auditforge.verify` (или `python -m auditforge.verify` на Python 3.11).
- Дополнительные проверки: `py -3.11 -m scripts.strict_sweep` и `py -3.11 -m scripts.profile_resources`.
- Локальный сайт: `py -3.11 -m auditforge.server --port 8765`.

Имя Python-пакета `auditforge` не меняется: переименован только каталог проекта. Публикуйте в существующий проект из `.openai/hosting.json`, сохраняя его текущую аудиторию. Для контекста используйте `README.md`, `PRODUCT.md`, `DESIGN.md` и `docs/`.

Старые временные скрипты в родительском `work/` могут содержать прежний путь. Не запускайте их без адаптации к текущей папке.
